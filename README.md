# Brew & Bean Café website

Open `index.html` in a browser (or use the VS Code "Live Server" extension).

- `index.html` – page structure and SEO tags
- `css/style.css` – colors and design (brand colors are at the top, in :root)
- `js/main.js` – café details (name, phone, WhatsApp, hours, social links), menu items and ordering. Edit the block under "EDIT THESE DETAILS".
- `images/` – photos. Replace a file with the same name to swap a photo.

Also update the café name, phone and address in the <title>, meta tags and JSON-LD block in `index.html`.
